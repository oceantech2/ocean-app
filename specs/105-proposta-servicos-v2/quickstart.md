# Quickstart: Propostas v2

## Preparar

```bash
docker compose up -d
cd frontend && npm run dev   # :5193
# API :8001
```

## Conferir

1. Login no Proposal → Nova proposta: sem Divisão/Modelo; marcar Recrutamento; setor Outros; gerar.
2. Link público: capa navy; serviço com metodologia; obs com **Impostos (18,75%)** (sem “até”).
3. Chrome → Baixar PDF: ~2 páginas, sem URL/data nas bordas, cards intactos.
4. Nova com setor Tecnologia: capa com foto.
5. Abrir proposta antiga (executive-search): ainda renderiza.
6. (Admin) Config imposto vigente refletido em `{imposto}`.
